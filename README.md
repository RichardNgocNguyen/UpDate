# upDate

## Description
An assignment to test if the implemented upDate class is properly overloading stream, arithmetic, and rational operators with the main.cpp authored by Steven H. Gold

## Getting Started
To compile, type in the terminal: <br>
(Windows)
```
g++ -o app.exe main.cpp upDate.cpp
```
(MacOS)
```
g++ -o app.out main.cpp upDate.cpp
```
To run, double-click the executable or navigate to the working directory of executable and type:
```
./app
```
